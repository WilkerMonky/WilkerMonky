## Projetos em Destaque

### IGRIS

Ecossistema de Trabalho de Conclusão de Curso para alocação acadêmica e otimização. Combina backend Spring Boot, frontend React e serviços especializados em Go e Python.

**Stack:** Java • Spring Boot • React • TypeScript • PostgreSQL • Go • Python

[Organização](https://github.com/igris-project) • [Backend](https://github.com/igris-project/igris-backend) • [Frontend](https://github.com/igris-project/igris-frontend) • [Rocket](https://github.com/igris-project/igris-rocket-service) • [Morpheus](https://github.com/igris-project/igris-morpheus-service)

### PGP Academy

Plataforma gamificada de programação desenvolvida de forma colaborativa. Minha contribuição incluiu o backend inicial em C# e ASP.NET, modelagem de banco, requisitos e planejamento técnico.

**Stack:** C# • ASP.NET • Banco de dados relacional

### Mione

Plataforma de gerenciamento de monitorias acadêmicas com repositórios públicos de backend, frontend e documentação. A documentação pública descreve backend Java/Spring Boot/PostgreSQL e frontend React/Vite/TypeScript.

**Stack:** Java • Spring Boot • PostgreSQL • React • TypeScript • Docker

[Backend](https://github.com/WilkerMonky/mione-backend) • [Frontend](https://github.com/WilkerMonky/mione-frontend) • [Docs](https://github.com/WilkerMonky/mione-docs)

### GradeMaker

Repositório público Java para um projeto de domínio acadêmico. Permanece listado como referência compacta enquanto a documentação pública é expandida.

**Stack:** Java

[Repositório](https://github.com/WilkerMonky/GradeMaker)
