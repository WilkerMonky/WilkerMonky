> ## Featured Projects
>
> ### IGRIS
>
> Computer Science capstone ecosystem for academic allocation and optimization. It combines a Spring Boot backend, React frontend and specialized services implemented in Go and Python.
>
> **Stack:** Java • Spring Boot • React • TypeScript • PostgreSQL • Go • Python
>
> [Organization](https://github.com/igris-project) •
> [Backend](https://github.com/igris-project/igris-backend) •
> [Frontend](https://github.com/igris-project/igris-frontend) •
> [Rocket](https://github.com/igris-project/igris-rocket-service) •
> [Morpheus](https://github.com/igris-project/igris-morpheus-service)
>
> ### PGP Academy
>
> Gamified programming platform developed collaboratively. My contribution included the initial backend, database modeling, requirements analysis and technical planning.
>
> **Stack:** C# • ASP.NET • Relational Database
>
> ### Mione
>
> Academic tutoring management platform divided into backend, frontend and documentation repositories.
>
> **Stack:** Java • Spring Boot • PostgreSQL • React • TypeScript • Docker
>
> [Backend](https://github.com/WilkerMonky/mione-backend) •
> [Frontend](https://github.com/WilkerMonky/mione-frontend) •
> [Documentation](https://github.com/WilkerMonky/mione-docs)
>
> ### GradeMaker
>
> Java backend project for managing academic domains, including users, institutions, components, grades and access profiles.
>
> **Stack:** Java • Spring Boot • PostgreSQL
>
> [Repository](https://github.com/WilkerMonky/GradeMaker)
